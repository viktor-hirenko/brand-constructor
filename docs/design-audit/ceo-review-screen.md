## Поле «Коментар CEO» без прыжка (Pages `2fcfeb17`)

Владелец 30.09 выбрал «не увеличивать»: поле правки в блоке открывается той же
высоты 68, что готовый комментарий (`CEO_SECTION_EDITOR_FLOOR_CLASS` `min-h-0!`
в `SectionCommentBlock.vue`), растёт только с текстом, до 5 строк.

Попутно найдено и исправлено: с фазы 11 (`48f1ff5`, 15.09) поля с автоподбором
высоты не росли — управляющий `flex-1` перебивал заданную высоту, строки сверх
пола скрывались (6 строк показывались как 3). `UiTextarea.vue`: после расчёта
высоты `style.flex = 'none'`. Касается всех таких полей: «Коментар» на шагах
визарда, «Загальний коментар», «Коментар CEO».

Замер на проде: «Коментар CEO» 68 → 68 при нажатии, 116 при трёх строках,
пустое из «+ Коментар CEO» — 68; «Загальний коментар» 96 → 168 (6 строк) →
312 (12, дальше прокрутка); «Коментар» шага 2: 96 → 168 → 216 (8, дальше
прокрутка).
